# 产品定义：ChatGPT / DeepSeek 严格线路切换

日期：2026-08-20
状态：用户已确认，进入开发

## 目标

让用户在 DSH 中切换模型时，聊天线路与搜索线路一起切换，避免 ChatGPT 模式下偷偷消耗 DeepSeek 配额。

## 用户可见规则

| 模式 | 聊天 | Web 搜索 | 其他能力 |
|---|---|---|---|
| ChatGPT | ChatGPT 订阅路由 | 仅使用已明确配置的 ChatGPT 兼容搜索；没有则明确提示不可用 | 仅使用能证明属于 ChatGPT 的能力；否则明确不可用 |
| DeepSeek | DeepSeek 路由 | 原有 DeepSeek 搜索 | 按 DSH 原有配置使用 |

## 必须满足

1. 切换到 ChatGPT 后，不得静默调用 DeepSeek 搜索或其他 DeepSeek 辅助线路。
2. 切换回 DeepSeek 后，恢复原有 DeepSeek 聊天与搜索配置。
3. 切换过程可逆，保留用户原始配置，不覆盖用户自定义线路。
4. 绑定、解绑、令牌失效、插件停用均有明确状态，不遗留旧凭据或错误线路。
5. 旧会话中用户明确选择的模型不被偷偷改写；默认模式切换影响新选择/默认选择，并在界面说明边界。

## 不在本次范围

- 把 ChatGPT 订阅凭据当作 OpenAI API key 或搜索 API key。
- 伪造 ChatGPT 搜索、视觉、图片、代码执行等并不存在的能力。
- 强制接管用户明确选定的旧会话模型。

## 验收标准

- ChatGPT 模式：DeepSeek 搜索 provider 被停用，通用搜索工具返回清晰不可用提示，不发生 DeepSeek 请求。
- DeepSeek 模式：DeepSeek 搜索 provider 恢复，搜索可用，配置与切换前一致。
- 绑定/解绑/重启后状态可恢复，用户自定义 provider 不被覆盖。
- 自动化测试覆盖正常切换、重复切换、异常回滚、用户配置保护和凭据清理。
