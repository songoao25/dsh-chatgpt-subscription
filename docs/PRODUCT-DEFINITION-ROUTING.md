# 产品定义：ChatGPT 订阅绑定（搜索配置用户自管）

日期：2026-08-20
状态：用户已确认（移除搜索管理，回归纯订阅绑定），进入开发

## 目标

让用户在 DSH 中通过官方 OAuth 绑定 ChatGPT 订阅并使用 ChatGPT 模型对话；**联网搜索等辅助能力的配置完全由用户自己管理**，插件不干预。

## 用户可见规则

| 能力 | 归属 |
|---|---|
| ChatGPT 模型对话 | 本插件（OAuth 绑定 + `openai-codex` 路由 + 令牌看护） |
| 默认模型切换 | 本插件在绑定/解绑时保存并恢复用户的默认模型选择 |
| 联网搜索（`searchProvider`） | **用户自行在 DSH 配置层指定**（如 `deepseek-official` / `exa`），与本插件无关 |

## 必须满足

1. 绑定 ChatGPT 后，插件不得读取、改写或切换任何搜索配置，不得把订阅令牌当作搜索凭据。
2. 解绑、令牌失效、插件停用后，不遗留插件自有凭据或错误路由；用户搜索配置在任何情况下不受影响。
3. 切换过程可逆：绑定前的默认模型被保存，解绑时恢复；用户自定义同名路由绝不被覆盖。
4. 旧会话中用户明确选择的模型不被偷偷改写；默认模式切换只影响新选择/默认选择。
5. 搜索是否可用由 DSH 自身规则决定（无可用搜索商时 `web_search` 明确失败），与本插件无关。

## 不在本次范围

- 把 ChatGPT 订阅凭据当作 OpenAI API key 或搜索 API key。
- 伪造 ChatGPT 搜索、视觉、图片、代码执行等并不存在的能力。
- 自动切换、停用或恢复任何搜索提供商。

## 验收标准

- 绑定/解绑流程不产生任何搜索配置写入（静态断言 + 运行时行为）。
- 绑定/解绑/重启后状态可恢复，用户自定义 provider 不被覆盖。
- 自动化测试覆盖绑定状态机、凭据生命周期、用户配置保护和凭据清理。
